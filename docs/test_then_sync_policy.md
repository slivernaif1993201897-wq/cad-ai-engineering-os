# Test-Then-Sync Policy

من الآن، لا تتم مزامنة أي تحسين أو تعديل إلى مستودع GitHub الأصلي قبل تنفيذ التحقق المناسب له وتسجيل النتيجة. تغييرات CAM/CNC تتطلب على الأقل فحصاً مركزاً للعقد، اختبارات الفشل fail-closed، lint/typecheck عند توفر الذاكرة، ثم مراجعة الفرق قبل الرفع على فرع مستقل. يبقى `main` دون تعديل مباشر؛ تتم المزامنة إلى فرع مراجعة ثم تُراجع عبر Pull Request.

إذا فشل full serial regression بسبب prerequisite خارجي مثل Gmsh أو runtime CAD مثبّت، تُرفع التغييرات التي اجتازت الاختبارات المركزة فقط، ويُسجل blocker صراحة، ولا يُعلن `PASS` شاملاً أو `MACHINE_CERTIFIED`.
